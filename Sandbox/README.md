# 연습

이 폴더는 연습과 생각 정리를 하는 곳이다. 마음대로 고치고 지워도 된다.

- 생각 정리: 떠오른 것을 `ideas.md`에 적는다.
- 연습: 해 보고 싶은 요청의 결과는 `practice/`에 둔다.
  - 연습마다 폴더를 하나씩 만들면 하나만 골라 승격하기 쉽다.
- 이 폴더에서 한 일은 작업기록을 남기지 않는다.

## 프로젝트로 승격

- 요청 예: 「Sandbox의 ○○ 메모와 practice의 ○○ 폴더를 프로젝트로 승격해 줘」
- 승격은 다음 순서로 진행된다.
  - 도구가 목표를 먼저 묻고 승격 계획을 올린다.
  - 승인을 받으면 `Projects/` 안에 폴더를 만들어 `plan.md`에 목표와 메모를 적고 결과 파일을 옮긴다.
  - 참조하던 자료는 `log.md`에 적고, 여기 원래 자리에는 승격한 곳을 남긴다.
- 프로젝트의 작업은 이 폴더를 참조하지 않는다.
